## 1. 目标与开始条件

在相同类别的输入、工具和上下文下，复现目标 Agent 的可观察流程、判断边界、确认门、异常处理和交接行为。不得声称还原官方原文。

开始条件：指定阶段模式由用户指定一个目标 Agent；完整模式若用户未指定，则从 S2 中选择直接页面证据最充分、对端到端结果最关键的 Agent 或自动化主体，并在第 1 章说明候选、选择标准和选择结果。S2 已确认其边界、输入、输出、工具和交接；已收集该主体全部出现记录；事实、推断、建议和未知可以追溯。没有可归属主体时仍保留 03 报告，明确“不适用、证据缺口和补证条件”，不得虚构身份或强约束。

## 2. 固定报告结构

使用 [../assets/functional-prompt-report.html](../assets/functional-prompt-report.html)，严格保留十章：

1. 目标 Agent 的证据范围；
2. 输入契约；
3. 输出契约；
4. 工具契约；
5. 状态机；
6. 事实规则、推断规则、建议规则；
7. 功能等价 System Prompt；
8. 规则—证据追溯表；
9. 最小测试集；
10. 仍然无法确认的问题。

第 1 章内固定回答边界十问：目标、接管时机、触发者、下游、职责内、职责外、修改重触发、必须停止、自动继续、确认门。

## 3. 状态、工具和规则契约

### 状态机

从实际行为选择状态，可包括 `waiting_input`、`planning`、`waiting_confirm`、`executing`、`validating`、`reconciling`、`retrying`、`failed`、`interrupted`、`handoff`、`completed`。每个状态写进入条件、允许动作、禁止动作、退出条件、上下文写入和用户反馈。事实状态与建议补强状态分开。

### 工具契约

每个有证据的工具规定：名称或 `<功能工具>`、调用时机、前置条件、参数、确认门、成功结果、回读验证、失败恢复、重试上限、幂等、中断、状态写入和计费/重复对象风险。只有计划证据的工具放入“待实现接口”。

### 规则分类

- `【事实规则】`：页面直接支持，必须保留。
- `【推断规则】`：为解释稳定行为所需。
- `【建议规则】`：为安全、幂等、可恢复和一致性新增。
- `【未知】`：不能写成强制的原产品事实。

为每条规则分配稳定编号，如 `F-01`、`I-01`、`R-01`、`U-01`，并引用证据或风险。

## 4. System Prompt 固定结构

代码区必须包含一个 Agent 名称行和以下十五个编号段落，顺序不变：

1. 角色；
2. 核心目标；
3. 任务边界；
4. 输入契约；
5. 全局上下文协议；
6. 工作流程；
7. 工具调用规范；
8. 用户确认机制；
9. 结果验证；
10. 修改与回退；
11. 异常处理；
12. 状态机；
13. 下游交接；
14. 完成条件；
15. 输出格式。

字段名不可见时用语义化占位名并注明“推导设计”；工具名不可见时使用 `<功能工具>`。输出 schema 未知时明确写成建议格式。

## 5. 测试与追溯

追溯表覆盖每条事实、推断和建议规则，至少包含规则 ID、规则摘要、类型、证据/设计理由、Prompt 段落和置信度。

测试至少六个，参考级默认八个：完整输入、缺少必要输入、局部修改、工具失败、用户中断、页面与上下文冲突，以及按产品风险选择重复请求、余额不足、安全拦截、权限拒绝、状态写入失败或下游启动失败。

每个测试包含：测试输入、初始状态、预期判断、预期工具、预期状态变化和禁止行为。

## 6. HTML 交互契约

- `data-report-profile="functional-prompt"`。
- 第 1 章包含十个 `data-boundary-question`。
- 四类规则分别使用 `data-rule-class="fact|inference|recommendation|unknown"`。
- 状态图提供可阅读视图和可复制 Mermaid，复制按钮指向稳定目标。
- System Prompt 使用可复制代码区；十五个编号段落使用 `data-prompt-section="1..15"` 标记。
- 测试使用 `data-test-case`，不少于六条。
- 页脚写停止边界：不继续拆其他 Agent，不冒充官方 Prompt。

## 7. 质量门

- [ ] 十章完整，第 1 章包含边界十问。
- [ ] 目标 Agent 全部记录已纳入，职责没有越界。
- [ ] 输入覆盖六类来源，输出覆盖五类结果。
- [ ] 工具成功后要求回读，不只相信 success。
- [ ] 状态机覆盖正常、修改、失败、重试、中断和交接。
- [ ] 四类规则均有编号，事实和推断可追溯。
- [ ] System Prompt 含 Agent 名称行和完整十五个编号段落。
- [ ] 修改、版本、失效、失败、重试和中断规则完整。
- [ ] 至少六个测试，且有禁止行为。
- [ ] 复制按钮和三档宽度检查通过。
